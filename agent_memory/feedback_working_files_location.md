On 28 Oct 2026 Claude kept the memory-and-knowledge Level 1/Level 2/tests drafts in /tmp. A session restart wiped them; Claude rebuilt them by replaying the session transcript. Swaraj was angry: he never asked for /tmp, he cannot open it, and he could not be shown proof the rebuild was exact.

**Why:** work files are his work product. They must survive restarts and be readable by him.

**How to apply:** put working drafts in a folder inside his project directory (ask which folder before the first write if not already agreed). Never use /tmp or the session scratchpad for anything he may need to read. If "no scratch notes in the repo" seems to conflict, ask him for the folder rather than choosing /tmp.
