Updated 2026-10-20. Earlier (2026-10-16) Swaraj wanted me to ask before agents, scratch files, audits, or edits. On 2026-10-17 he changed that: "if we decided, then now just do... avoid asking questions". He was annoyed at being asked about execution details that were already settled.

**Why:** Asking about settled points wastes his time. Running ahead on undecided work wastes his money. Both have happened.

**How to apply:**
- Steps the record already decides (the next file in the agreed order, the file split inside a view, the two audits after every write, reusing the same audit agents for a re-audit): just do them.
- Stop and ask only for a real gap, a conflict between sources, or something only he can decide (for example whether a Level 2 answer is accepted). Bring the full picture with the question: story, rule, where it is written, status.
- Still never create scratch notes in the repo, and never edit Level 2 or foundation files beyond the request without asking.
- Long files are fine (2026-10-20). Don't stop to ask about splitting at 300 lines.
- Decisions go in `knowledge_base/architecture/construction_record.md`, entry 21. The Cursor handoff prompt is `section_12_starting_prompt.md` at the repo root.
