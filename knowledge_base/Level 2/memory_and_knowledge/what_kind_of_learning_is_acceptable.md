# What kind of learning is acceptable?

## Status

Answered — working decision, pending review.

## Acceptable learning

Tend may learn to improve:

- how it interprets local language;
- how it identifies a situation;
- how it retrieves relevant information;
- how it prioritises gathering;
- which tool or source it considers first;
- which tool preconditions it checks;
- how it constructs tool arguments;
- how it recognises its own failure patterns;
- when it asks for clarification;
- when it waits or escalates;
- how it communicates with a particular business; and
- how it transfers work to people.

## Unacceptable learning

Tend may not learn to change:

- business rules;
- formal policy;
- legal or compliance constraints;
- authority;
- permissions;
- ownership;
- required approvals;
- source-of-truth responsibility;
- accountability; or
- irreversible-action boundaries.

## Descriptive and normative knowledge

Learning may produce a description such as:

> This business usually checks the warehouse system before contacting the carrier.

It may not turn that observation into:

> The warehouse system is always authoritative.

The first is a procedural lesson. The second is an authority decision.

The business or system must establish the second explicitly.

## The learning boundary

The simplest test is:

> Does this learning improve Tend’s way of operating, or does it change what the business is allowed or required to do?

The first is within learning.

The second is outside learning.

## Working decision

Tend may learn about itself and the local operational environment so that it performs better for a business.

It may not learn to redefine the business’s rules, authority, ownership or accountability.
