# How do we update knowledge when reality changes?

## Status

Answered — working decision, pending review.

## Updating does not mean rewriting

The earlier situation-model decision already established that corrections happen forward.

The old state remains available.

A new observation creates a new version or a new claim state.

The reason for the change is preserved.

The same principle applies to learned knowledge.

## Possible update meanings

A new learning instance may:

- add a new memory;
- refine an existing memory;
- narrow its conditions;
- supersede an older version;
- create an exception;
- create a conflict;
- mark an item stale;
- reject a candidate; or
- do nothing because it adds no new information.

The system should not force every update into “replace the old value.”

## Reality and Tend’s learning are different

When a business policy changes, the business owns that policy change.

Tend may observe the change and update the context it uses, but automatic learning must not pretend that Tend discovered or authorised the policy.

When Tend makes a tool-use mistake, Tend may create a new error lesson without changing the tool’s formal contract.

## Working decision

Knowledge changes through traceable additions, revisions, supersession, conflicts and retirement while historical observations remain preserved.

The update operation depends on the memory type and its structured claim family.

No learning update silently destroys the previous record.
