# Module 7 — A design language for Tend (learning record)

> The synthesis: every scale the pillar pre-picked, written into one artifact — so five hundred screens agree without anyone remembering. Same contract: Tend the example only; forms below are shapes to borrow, never decisions.

**The shelves (all pre-picked earlier, gathered here):** type scale, px/rem, line-heights, the 45–75 rule (§4) · spacing scale, 16px base, ≥25% steps, "more around the group than within" (§3) · shade palettes, 8–10 greys, 5–10 primaries, meaning-accents, one temperature (§5) · five-shadow elevation, z-positions, modal on top (§6) · letter-spacing at the edges (§4) · state words (§5) · motion timed once (Module 4).

**Story order before tokens.** Every surface tells one story, owner's side: **Blocked** (decision owed — highest weight) → **Changed** (new facts — second) → **Waiting** (reply owed — third) → **Quiet** (nothing needed — the floor). Tokens only *deliver* the ranking — elevation, weight, tint, one motion — never a dialect per page.

**State words, one meaning each:** WAITING (reply owed) · ACTIVE (work moving) · BLOCKED (decision owed *by the owner*) · RESOLVED (honest ending: answered / deferred / escalated / declared unanswerable). Machine side keeps the same four as gate values — one vocabulary, two perceivers (dual-surface ruling).

**Motion, each timed once:** arrive (feedback lands) · state-change (transition narrates) · escalate (modal lifts). Earning paid, silence after.

**Borrowed, not decided:** Communication's minimum-sufficient depth · Explainability's honest endings · Business View's attention rules (`which_events_should_require_the_owners_attention`) + exception-first reading. Content lent by Level 2; tokens are where borrowed content becomes visible form.

**The tightest link in the pillar:** exceptions don't complain, don't narrate, don't decorate — they POINT. Highlight at the edge (RUI §7, UP p.108), weight up, everything else down. The exception view is every unit in one screen.

**Echoes:** tokens ↔ "limit your choices" (§1) grown into an artifact — never re-argue an agreement. Story-first ↔ H10 Advance Organizer (UP pp.52–53). State words ↔ "color never alone" + honest endings. Motion-once ↔ motion-with-purpose.
