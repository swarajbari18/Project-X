# Plans

Swaraj decided on 4 November 2026 that plans live here, inside the knowledge base, and not at the root of the repository.

**How this folder is laid out.**
- One folder per component.
- Inside it, one folder per plan. A component takes several plans.
- Each plan's folder holds two files:
  - `plan.md`: the plan, in natural language, with its locked tests. It contains no code.
  - `record.md`: the final record, written after the plan is translated and reviewed.

**Where each file's rules come from.** `knowledge_base/software_factory_with_coding_agents.md`, Stage 2 for plans and Stage 5 for records.

**Components so far.**
- `situation_registrar/`: the first component. The design's older files call it the situation record.
