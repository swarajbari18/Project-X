# Code index for the responsibility view (agent-only)

This file is for agents. It is not meant to be read in the rendered view. Every rule code used in this folder appears here, with its plain meaning, its source, and its status.

The rows are taken from `../../code_index_section_6.md`, which is now the history of these codes. Where a rule has no code yet, the hidden note in the file carries its source instead.

**Status values** (the folder's four; see [`../map.md`](../map.md)):
- **Decided** — the owner decided it, or accepted it on 2026-10-22.
- **Provisional** — a working choice; it carries a condition for reopening it.
- **Rejected** — refused on purpose; the reason is kept.
- **Deferred** — a value or a detail left to a later stage. A row may say which: deferred to configuration, deferred to Level 3, or deferred to implementation.

The earlier words **To confirm** and **Open** are no longer used. They appear only in the historical notes below, which describe this folder as it stood before 2026-10-22.

Where a rule came from is separate from its status.

Level 2 governs. Where another source disagrees with Level 2, Level 2 wins and the disagreement is written down. One exception: where a later owner decision in the construction record changes a Level 2 sentence, the owner's decision governs until the Level 2 sentence is edited, and the row says so (construction record, entry 21: "The later instruction wins where they conflict").
